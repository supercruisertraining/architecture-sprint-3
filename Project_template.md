### 2. Анализ архитектуры монолитного приложения
Основанием данной системы является веб-приложение на Java/Spring, использующее СУБД Postgresql. Взаимодействие с системой идёт через HTTP API интерфейс.

### 3. Определение доменов и границы контекстов

В рамках монолитного приложения выделены два домена:
- Домен управления температурой (просмотр, изменение)
- Домен хранения и обработки данных

### **4. Проблемы монолитного решения**

- Низкая способность к масштабированию
- Сложность в добавлении новых функций
- Более трудозатратный онбординг новых сотрудников
